## Задача 1. Очки фитнес-браслета

LeetCode 1176 (на LeetCode задача платная, условие целиком здесь).
`step_score(steps, k, lower, upper)`: `steps[i]` — шаги за день `i`.
Каждые `k` дней подряд браслет оценивает сумму шагов: меньше `lower` —
минус очко, больше `upper` — плюс очко, от `lower` до `upper`
включительно — ноль. Вернуть сумму очков по всем окнам.

| Вход | Ответ | Почему |
|---|---|---|
| `[1, 2, 3, 4, 5]`, `k = 1`, `lower = upper = 3` | `0` | −1, −1, 0, +1, +1 |
| `[3, 2]`, `k = 2`, `lower = 0`, `upper = 1` | `1` | одно окно, сумма 5 |
| `[6, 5, 0, 0]`, `k = 2`, `lower = 1`, `upper = 5` | `0` | суммы 11, 5, 0: +1, 0, −1 |

## Задача 2. Кодовый замок

LeetCode 1652. `decrypt(code, k)`: числа записаны по кругу, после
последнего снова идёт первое. Каждое число заменяется суммой `k` следующих
чисел при `k > 0`, суммой `|k|` предыдущих при `k < 0` и нулём
при `k = 0`. Вернуть новый список.

| Вход | Ответ | Почему |
|---|---|---|
| `[5, 7, 1, 4]`, `k = 3` | `[12, 10, 16, 13]` | для 5: 7 + 1 + 4; для 7: 1 + 4 + 5 |
| `[1, 2, 3, 4]`, `k = 0` | `[0, 0, 0, 0]` | |
| `[2, 4, 9, 3]`, `k = -2` | `[12, 5, 6, 13]` | для 2: 3 + 9; для 4: 2 + 3 |

Индекс по кругу — остаток от деления: `code[i % len(code)]`.

## Если не работает

| Признак | Что проверить |
|---|---|
| `pytest: command not found` | окружение не активировано: в начале строки терминала нет `(.venv)` |
| `ModuleNotFoundError: solution_05` | команда запущена не из корня репозитория или файл переименован |
| `NotImplementedError` | тело функции ещё не написано |
| Падает `test_score_bounds_are_inclusive` | сравнения строгие не там: сумма, равная `lower` или `upper`, даёт ноль |
| Падает `test_score_k_is_n` или ответ меньше на одно окно | последнее окно не проверяется: окон всего `n − k + 1` |
| Падает `test_decrypt_k_is_minus_one` | при `k < 0` берутся следующие числа вместо предыдущих |
| Падает `…_fast_enough` | сумма каждого окна считается заново срезом или `sum` в цикле |
