## Задача 1. Лодки на сплаве

LeetCode 881. `min_boats(weights, limit)`: в лодку садятся один или два
человека, общий вес не больше `limit`. Вернуть наименьшее число лодок.

| Вход | Ответ | Почему |
|---|---|---|
| `[1, 2]`, `limit = 3` | `1` | оба в одной лодке |
| `[3, 2, 2, 1]`, `limit = 3` | `3` | (1, 2), (2), (3) |
| `[3, 5, 3, 4]`, `limit = 5` | `4` | никакие двое вместе не помещаются |

Список `weights` менять нельзя. Время O(n log n).

## Задача 2. Сначала чётные

LeetCode 905. `even_first(nums)`: переставить числа на месте так, чтобы все
чётные стояли раньше нечётных. Порядок внутри групп любой, функция ничего
не возвращает.

| Было | Подходит, например |
|---|---|
| `[3, 1, 2, 4]` | `[2, 4, 3, 1]` или `[4, 2, 1, 3]` |

Новые списки не создаются: память O(1). Время O(n).

## Если не работает

| Признак | Что проверить |
|---|---|
| `pytest: command not found` | окружение не активировано: в начале строки терминала нет `(.venv)`. Команды — в README репозитория |
| `ModuleNotFoundError: solution_04` | команда запущена не из корня репозитория или файл переименован |
| `NotImplementedError` | тело функции ещё не написано: строка `raise NotImplementedError` осталась |
| Падает `test_boats_does_not_change_input` | список отсортирован на месте через `.sort()`. Нужна копия: `sorted(weights)` |
| Падает `test_boats_heavy_takes_lightest` | тяжёлого сажают с соседом по весу, а не с самым лёгким |
| Падает `…_fast_enough` | решение медленное: вложенный цикл, `pop(0)` или `insert` внутри цикла |
| Падает `test_even_first_constant_memory` | создаются новые списки или срезы. Числа переставляются обменом внутри `nums` |
